Pros & Cons

compose-highlight CH

  • Smaller APK impact (628 KB)
  • 190+ languages bundled out-of-the-box
  • Built-in UI features (line numbers, copy, label)
  • Automatic dark/light theme switching
  • WebView dependency (heavier runtime)
  • Not truly Compose-native rendering
  • Limited customization of rendered output
  • Main-thread only (WebView constraint)

kotlin-textmate KT

  • Pure Compose rendering (AnnotatedString)
  • 600+ languages via standard TextMate grammars
  • No WebView dependency
  • Full control over rendered output
  • Native text selection
  • Larger APK impact (1.6 MB)
  • Joni encoding tables are heavy (~1.3 MB)
  • Bring-your-own grammar files
  • Fewer built-in UI conveniences
  • v0.1.0 — early stage, no injection grammars

When to Use Which

Choose compose-highlight if: APK size is a priority, you need quick integration with minimal setup, you want built-in UI features (line numbers, copy button), or you're already using WebView elsewhere in your app.
Choose kotlin-textmate if: You need Compose-native rendering with full text selection, you want to use standard VS Code grammars/themes, you need fine-grained control over the highlighted output, or you're building a code editor where native text interaction matters.
